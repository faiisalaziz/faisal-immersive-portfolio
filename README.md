# Faisal Aziz — Immersive AI/ML Portfolio

A React portfolio with a continuous Three.js environment, scroll-driven camera travel, interactive project concept demos, and responsive layouts.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Build

```bash
npm run build
```

## Edit portfolio content

- Update profile, skills, experience, and project copy in `src/data.js`.
- Replace project `github` values with the real repository URLs when available.
- The City Fix, Space Har, and TechVerse previews are front-end concept demos. They do not call external services or represent connected production systems.
- The portrait is in `public/faisal-portrait.png`.

## Stack

React, Three.js, GSAP ScrollTrigger, Framer Motion, and Lenis.
